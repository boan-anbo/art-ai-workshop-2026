# Agent Instructions

This is a workshop workspace. `projects/` is the working location.

- To start a project, copy `templates/project_template/` to `projects/<project_name>/` (lowercase, underscores).
- Keep original source materials in `sources/raw/`; never edit them in place.
- Put cleaned, OCRed, described, or transformed materials in `sources/processed/`.
- Put large generated outputs, indexes, and caches in `artifacts/`; do not commit them unless the human asks.
- Put notes, drafts, and outputs in `research/`; project-specific code in `code/`.
- If the target project is unclear, ask before writing files.

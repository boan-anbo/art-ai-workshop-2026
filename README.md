# AI Tools Workshop, CUHK Fine Arts 2026

Start here: [Session 1, what to do before 6 November](sessions/session-1/instructions.md)

Workshop workspace for the two-session AI tools workshop, Department of Fine Arts, CUHK, November 2026. You will fork this repository and work in your own copy.

This repository is the single source for the workshop: all instructions, materials, and updates land here. If something changes, it changes here first.

## The two sessions

1. **Vibe Coding for Art Research** — Thursday 6 November, 2:30–4:30 PM. Set up an AI coding agent on your own laptop and go from a research question to a small working tool: organize your materials, extract text, generate descriptive text for images, build a small searchable catalog of your own sources.
2. **Vibe Coding for Art Research Presentation** — Thursday 13 November, 2:30–4:30 PM. The presentation side, from capture to publication: 3D capture and Gaussian splatting, IIIF and Mirador, image and video generation, interactive maps (MapLibre/GIS), Three.js, web AR, scrollytelling, and a virtual exhibition site assembling it all.

## What is in this repository

- `sessions/` one folder per session; each holds its own `instructions.md`, posted before the session
- `templates/project_template/` the structure every project starts from: `research/`, `sources/`, `artifacts/`, `code/`
- `projects/` where your own work will live
- `AGENTS.md` the rules an agent follows inside this workspace

Nothing else here needs to be read in advance. Do the session 1 instructions, and we will open the rest together.

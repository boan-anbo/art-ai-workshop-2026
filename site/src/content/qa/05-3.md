<strong>假設情境 · 英文：</strong>

<details class="original-question">
<summary>English · hypothetical scenario</summary>
<blockquote lang="en">Suppose a project searches twenty illustrated or print books for a particular visual motif, such as a type of animal or object, and then studies its contexts and accompanying figures. Is this feasible, and which models or tools could help?</blockquote>
</details>

假設在二十本版畫或插圖書中尋找某一特定圖像母題，例如某種動物或器物，可以分成<strong>尋找候選 → 標註情境 → 論證意義</strong>三步。最後一步仍需要比較與文獻證據。

先固定版本與逐頁清單（page manifest），記書名、文類、刊刻年代、原書葉碼、掃描頁序及原圖。用人工確認的正例、反例和困難頁測試整頁描述、局部裁切與相似檢索。每個命中返回原頁，未命中的頁也抽查；若要宣稱找出全部例子，完整逐頁覆核最直接，排序不能證明沒有漏頁。

少數圖像可以逐件對話，成批書籍則應讓 coding agent 寫程式，<strong>逐頁獨立呼叫 API</strong>。每頁使用相同任務與必要背景，避免前頁判斷污染下一頁。第一輪先客觀描述全頁的人物、場景、動物與器物，再篩選目標母題；不要一開始反覆問是否有目標，讓模型迎合期待。

可先用較便宜的 Gemini Flash／Lite 類模型批量描述，另一模型或較強的 Judge 審查疑難頁。先比較文字描述、找相似組，再回原圖比較。將確認或疑似目標裁切放大成局部 gallery，讓研究者肉眼觀察姿態、位置、伴隨人物與構圖規律。每輪保留原頁連結、模型版本及未確認項。

確認候選後，再記動作、場景、伴隨人物、題記與不確定處；共現不自動證明互動關係。以清楚的 codebook 定義分類，再用同頁正文、榜題、相關文獻和反例檢查競爭解釋，分開可見分布與象徵論證。

同版重印、翻刻或粉本借用可能反映出版流傳，不能當成多次獨立描繪。比較還要有<strong>分母與基線</strong>：假設目標母題的圖像有 70% 出現在某類場景，但整批插圖本來也有 70% 屬該場景，就不能只憑比例說目標與這種場景特別相關。用不含目標的頁面與反例對照。

自己的 coding agent（OpenCode／Claude Code／Codex）可透過同一個 OpenRouter API key 安排視覺描述與 embeddings。文字描述可用文字向量，直接處理圖像時需選支援圖像輸入的模型；相似度只提供候選，不直接證明意義。

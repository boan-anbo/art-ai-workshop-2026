**原問題：**

<details class="original-question">
<summary>英文原問題</summary>
<blockquote lang="en">Is using AI tools to extract data on each artifact from archaeological reports in order to build a database a feasible approach? How can the accuracy of data extraction be improved?</blockquote>
</details>

可行。先確認一條記錄代表一件器物、殘片還是一組材料，再用一份報告的小樣本定欄位。正文、表格與圖版可能重複描述同一件器物，必須處理識別碼與重複計數。

要求每個提取值帶原文、頁碼或圖版位置；保留原標法，另外做名稱和單位規範化。準確性既包括**值有沒有讀錯，也包括漏件與重複**。人工對照樣本要包含跨頁表格、缺值和難例，再按 OCR、讀序、提取、合併等錯誤修訂方法。

可先用 CSV，確實需要多表連接時再用 SQLite。[LangExtract](https://github.com/google/langextract) 等工具可協助把提取連回文字位置，結果仍要核查。Workshop 會從少量器物資料走完提取、查驗與一次修訂。

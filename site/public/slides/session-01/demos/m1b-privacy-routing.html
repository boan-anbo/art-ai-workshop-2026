TIER 1 · EVERYDAY LAPTOP

MacBook Air / Pro (16–36 GB)

HK$ 10,000 – 22,000

What runs locally: Tiny 7B–14B quantized models (via Ollama / LM Studio) + local Whisper / PaddleOCR.

Ceiling: Weak on classical Chinese (文言／題跋), poor instruction following, and hallucinates citations heavily.

TIER 2 · HIGH-VRAM WORKSTATION

Mac Studio Ultra (192–512 GB) / Dual 4090

HK$ 35,000 – 85,000

What runs locally: Medium 32B–70B dense models or quantized MoE models at ~15–25 tok/s.

Ceiling: Usable for local text drafting & basic extraction, but still lags frontier cloud models on complex multimodal vision.

TIER 3 · FULL FRONTIER OPEN-WEIGHT

Mac Pro / Multi-GPU Server (671B MoE)

HK$ 150,000 – 450,000+

What runs locally: Full-weight DeepSeek V3/R1 (671B) or GLM-5 / Qwen3 without heavy quantization loss.

Takeaway: 100% private, but prohibitively expensive for an individual student — and still lacks cloud-scale visual world knowledge.

NOTHING UPLOADED TO THE CLOUD IS 100% INVISIBLE — COMPARE INFERENCE ROUTES & LAB POLICIES
Provider / Route Privacy & Inspection Reality Specific Risk to Researchers Trust Tier
1. Third-Party Wrappers
(e.g. WorkBuddy / 套殼軟體)		 Intermediary server logs prompts; opaque retention; aggressive content filtering. Prompts pass through unverified middleman servers; political/historical terms get silently blocked or logged. AVOID (最不推薦)
2. DeepSeek Direct / OpenRouter China Toggle OpenRouter recently added an explicit toggle: you must enable Mainland China data routing to use official DeepSeek endpoints. Data routed onshore is subject to domestic compliance & content rules; US-hosted DeepSeek (Fireworks/Together) has different terms. MIXED (視路徑而定)
3. OpenAI
(ChatGPT / API)		 Backend safety classifiers & human reviewers can and do inspect flagged content (including external reporting cases). Credible cases of mathematicians suspecting unpublished proofs/problems were absorbed; internal employee permissions are not air-tight. CAUTION (勿傳獨門原創核心)
4. Anthropic
(Claude)		 Explicitly classifies China (and often HK/Macau institutional contexts) as an adversarial region (敵對地區). National-security / adversarial-use policy gives them broad extra justification to audit, inspect, or suspend your account & materials. EXTRA AUDIT RISK (額外審查風險)
5. Google Cloud / Gemini API
(via Paid API / OpenRouter ZDR)		 Standard enterprise cloud infrastructure; paid API tier does not train on customer payloads by default. Relatively more predictable than startup labs or wrapper apps, though still a cloud service. RELATIVELY BETTER (大廠相對較穩)
MANDATORY SETTINGS · TURN ALL DIAGNOSTICS & TRAINING TO "NO"
1. OpenCode / VS Code / Desktop Apps: "Send usage diagnostics & crash telemetry" SELECT: NO / OFF
2. OpenRouter Privacy Settings: "Allow providers to train on or log prompts" SELECT: NO (ZDR ONLY)
3. OpenRouter Mainland China Data Routing: Only enable if using public/non-sensitive material DEFAULT: OFF
4. ChatGPT / Claude Web Consumer Toggle: "Improve the model for everyone" SELECT: OFF
HOW TO USE AI WITHOUT LEAKING YOUR RESEARCH CORE

Rule 1 · Ask the Agent to Write Local Python Scripts:
Do not upload 500 private archive pages to the cloud! Ask OpenCode to write a Python script using 1 dummy sample; then run that script 100% locally offline on your real corpus.

Rule 2 · Send Isolated Crops, Not Your Thesis Argument:
When using Vision/OCR on an inscription, send only the cropped character/column image without your unpublished historical thesis or archive call number.

Rule 3 · Keep Core Original Thesis Writing Local:
Write your core original argument in local Markdown (`*-human-reflection.md`) with AI autocomplete turned off.

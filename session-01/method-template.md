# 把一次有效工作寫成方法

把以下內容複製到自己工作區的 Markdown 檔，再按材料修改。先用一頁／一張圖試做；這是可重用的工作規則，不是模型權重訓練。不同 agent 的 skill 存放和載入方式不同，請讓自己的工具說明並確認它實際讀了此檔。

## 目的與範圍

我想回答的研究問題：……

本次只處理：……（列明檔案／頁面／版本）。不以模型記憶補寫來源沒有的歷史事實。

## 輸入

保留原材料；OCR、裁切、譯文和機器描述另存。記來源 id、取得日期、印刷頁碼及掃描頁序；圖像局部要能定位回原頁。材料必須適合交給所選工具處理。

## 步驟

1. 確認材料可讀及本次要處理的單位。
2. 按指定欄位產生候選。保留原詞；正規化、翻譯及推測另列。
3. 每項附原文／可見描述及頁碼或區域。未知寫未知，不為了填滿表格猜測。
4. 查重複、單位、日期、身份與欄位角色；例如出土地與現收藏地分開。
5. 回原材料核對有用候選，另看未命中材料是否漏取。未核對的不標成已確認。

## 輸出

一份小候選表或筆記：記錄 id、原詞／觀察、整理欄位、來源定位、核查狀態、疑點。另記已處理範圍和未處理項目。

## 停止與修訂

材料不可讀、來源無法定位、同名無法判定、表格關係不清或權限不足時，保存疑點並停下該項。不要補答案。

記下一個具體失敗：哪個例子、錯在哪、改了哪條規則、再試結果如何。另拿一個新例子核查；方法改動後保留版本與理由。

最後寫一句：這次結果能支持甚麼，仍不能支持甚麼。

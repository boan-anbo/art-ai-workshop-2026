description: Describe one image so it can be searched by subject and by style; what is visible first, guesses marked.
---

One image per call. Write four short parts:

1. Subject: what is shown, and where in the picture.
2. Style and medium: how it is made (for example watercolour, ink and colour, woodblock print).
3. Visible text: inscriptions, seals, captions, exactly as written; [?] where you cannot read it.
4. Guesses: date, place, maker, purpose. Mark each as a guess and give its reason.

Do not assume my hypothesis; "none" is an acceptable answer.
Save to `my-work/sources/processed/<image name>.description.md`. Never change the image.

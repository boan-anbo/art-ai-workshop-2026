---
name: agent-browser
description: Open and read pages in a real browser, on sites that allow it, as a person would.
---

1. Use agent-browser (https://github.com/vercel-labs/agent-browser) only on sites whose rules allow automated access; check robots.txt first.
2. The researcher logs in and solves CAPTCHAs. Never bypass them.
3. Save downloads to `my-work/sources/raw/`, named by source (e.g. `ccc-1908.pdf`), and add a row to `my-work/sources/raw/manifest.csv`: file, source, link, date, rights.
